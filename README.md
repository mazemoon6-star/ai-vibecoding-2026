# ai-vibecoding-2026

바이브코딩 리포지토리


## Chapter 1
AI에게 코딩을 시키자, 제대로!

### 개념
코딩을 직접하지는 말 것. AI와 협업해서 새로운 프로그램을 만들자

#### 기존의 개발방법
요구사항 분석 -> 설계(DB/UI 포함) -> 구현/디버깅 -> 테스트 -> 배포 -> 유지보수

### 바이브코딩 방식
요구사항정의(PRD) -> AI 코드 생성/디버깅,테스트 -> 사람 **검증** 수정 요청, 직접 수정 -> 배포 -> AI 유지보수

#### 핵심 포인트
- AI - 주니어/시니어 개발
- 사람 - PM + 리뷰어

### 바이브코딩 개발환경
- VS Code, VS Code Insider, Android Studio, ... 

### VS Code
