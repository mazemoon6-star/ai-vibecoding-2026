섹터 자동 발굴·매매

자동 발굴 꺼짐

섹터 검색 → 종목 선택 → 투자 비율 지정 → 시작. 선택 비율은 종목별이 아닌 섹터 전체 투자 한도입니다.

가용현금을 확인하고 있습니다.

거래 방식·주의사항

섹터 검색이나 Enter는 조회만 합니다. 시작 버튼을 누를 때 선택 종목과 현금 투자 비율이 적용됩니다.

국내 주식의 시작 시점 가용현금으로 섹터 한도를 정하고, 거래대금·주가를 반영해 종목별로 자동 배분합니다. 매수 수수료를 포함하며 1주를 살 수 없는 잔액은 현금으로 남깁니다.

다른 섹터를 시작해도 기존 자동매매 종목과 한도는 유지됩니다. 이평선 매수 신호가 발생하면 PAPER 주문을 실행하며, 기존 보유분을 비중 조정 목적으로 자동 매도하지 않습니다.

자동 발굴을 시작하면 종목 선정과 전략 실행이 이어집니다.
